# 02. 使用者身分型別與權限矩陣規格書 (RoleType & Permission Specifications)

> **所屬系統**: SurveyFlow 現代實證調研與學術結構化數據採集系統  
> **更新日期**: 2026-10-22  
> **文檔定位**: 專案全域身分認證、授權模型與權限存取控制 (RBAC) 之唯一真實規格標準。緊接系統概述，負責明確定義「使用者是誰、各身分能做什麼」。

---

## 1. 核心身分定義 (Core Roles)

系統依據業務權限最小化與責任隔離原則，定義三種核心身分型別 (`RoleType`)：

1. **訪客 (`GUEST`)**:
   - 未登入之一般公眾或匿名受訪者。
   - 免註冊、免憑證即可直接填答公開問卷或透過專屬直達連結進入填寫。
   - 嚴格隔離管理與設計功能，存取設計端自動引導登入。

2. **一般會員 (`MEMBER`)**:
   - 完成註冊並通過 Email 啟用碼驗證之實名調研發起人。
   - 具備名下問卷完整管轄權（建立、預覽、分享連結、時限設定、查看數據、匯出報表與刪除）。
   - 僅能操作自己名下所擁有之問卷，嚴格禁止越權存取其他會員之問卷與數據。
   - 遵循問卷上傳發布後鎖定結構之不可溯及修改原則，無二次修改已發布題目之行為。

3. **系統最高管理員 (`ADMIN`)**:
   - 平台最高營運與稽核管理者（如系統維運者）。
   - 具備全站會員名冊檢視、會員狀態調整（啟用/凍結）與違規帳號刪除管理權。

## 2. 三大身分功能權限對照比較矩陣 (Role & Function Matrix)

> 標記說明：
> - `✅`：具備完整操作權限。
> - `❌`：無權限（前端介面不展示按鈕或觸發攔截、後端 API 拋出 401/403 阻斷）。
> - **零虛構原則**：本表僅列出系統 100% 真實實作之功能，未實作者一律不入列。

| 業務功能項目 | 訪客 (`GUEST`) | 一般會員 (`MEMBER`) | 系統管理員 (`ADMIN`) | 實體控制端點 / 業務防線規範 |
| :--- | :---: | :---: | :---: | :--- |
| **瀏覽大廳公開問卷清單** | ✅ | ✅ | ✅ | `GET /api/public/surveys/lobby` (分頁檢索) |
| **填寫大廳公開問卷** | ✅ | ✅ | ✅ | `POST /api/public/submissions` (免登入作答) |
| **填寫私有連結問卷** | ✅ | ✅ | ✅ | `GET /api/public/surveys/{id}` 持連結可載入作答 |
| **建立新問卷專案** | ❌ | ✅ | ✅ | `POST /api/user/surveys` 進入視覺化設計器建立 |
| **預覽名下問卷專案** | ❌ | ✅ | ✅ | 預覽模式不計入正式填答統計 |
| **複製問卷專屬作答連結** | ❌ | ✅ | ✅ | 複製直達作答 URL 分享受訪者 |
| **調整名下問卷開放狀態與時限** | ❌ | ✅ | ✅ | `PUT /api/user/surveys/{id}/settings` (雙狀態切換與時限) |
| **關閉名下問卷填答通道** | ❌ | ✅ | ✅ | 即時停止填答，阻斷新受訪者作答 |
| **調閱名下問卷數據分析報表** | ❌ | ✅ | ✅ | `GET /api/analytics/surveys/{id}`，非擁有者拋出 403 |
| **匯出名下問卷統計數據** | ❌ | ✅ | ✅ | 支援 CSV、Excel (UTF-8 BOM)、SPSS (.sps)、JSON 匯出 |
| **刪除名下問卷專案** | ❌ | ✅ | ✅ | `DELETE /api/user/surveys/{id}` 軟刪除 |
| **維護個人基本資料** | ❌ | ✅ | ✅ | `PUT /api/user/profile` (身分證字號唯讀保護) |
| **修改登入密碼** | ❌ | ✅ | ✅ | `PUT /api/user/password` 驗證舊密碼並更新 |
| **檢視全站會員清單** | ❌ | ❌ | ✅ | `GET /api/admin/users` 僅限 ROLE_ADMIN |
| **調整會員帳號狀態 (啟用/凍結)** | ❌ | ❌ | ✅ | `PATCH /api/admin/users/{id}/status` 即時凍結/啟用會員 |
| **刪除會員帳號資料** | ❌ | ❌ | ✅ | `DELETE /api/admin/users/{id}` (內建 admin 保護機制) |

## 3. 前端路由守衛與介面隔離規範

1. **未登入訪客攔截 (`authGuard`)**:
   - 當訪客嘗試存取 `/survey-design`（設計器）、`/survey-management`（專案管理）、`/user-profile`（個人資料）時，路由守衛立即阻斷並導向 `/log-in`，提示使用者登入。
2. **一般會員存取管理員頁面攔截 (`adminGuard`)**:
   - 當一般會員嘗試存取 `/user-management`（會員管理）時，守衛檢查當前使用者權限，若非 `ROLE_ADMIN`，立即阻斷並導向產品首頁 `/home`。
3. **無效功能按鈕隱藏**:
   - 介面依據當前登入身分動態渲染頂部導覽列：訪客顯示「登入/註冊」；會員顯示「問卷管理、個人資料」；管理員額外顯示「會員管理」。
